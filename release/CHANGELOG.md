# Журнал изменений (Changelog)

## Версия 2.3.0 (Релиз)

### 🚀 Новые возможности
* **3 режима маршрутизации и фильтрации для каждого устройства:**
  * `🚀 VPN` — весь трафик и DNS (`1.1.1.1:53`) идут строго через туннель AmneziaWG (`awg0`), мимо Zapret и GeoHide.
  * `🛡 Zapret + DoH` *(по умолчанию)* — прямой выход через провайдера с активным обходом DPI (`zapret`) и шифрованным DNS (`https-dns-proxy` / GeoHide EU).
  * `🌐 Без ничего` — полностью чистый канал провайдера без VPN, без Zapret (обход через `ct mark & 0x00800000`) и без `https-dns-proxy` (DNS напрямую к серверу провайдера из `resolv.conf.auto`).
* **Закрепление статического IP (`📌 Закрепить IP`):**
  * Кнопка привязки IP к MAC-адресу в DHCP прямо из таблицы устройств.
  * Подсветка устройств со случайным (приватным) MAC-адресом.
* **Мониторинг DoH, Zapret и кнопка перезапуска `awg0`:**
  * В панели статуса отображается активность `https-dns-proxy` (DoH), `zapret` и текущий DNS провайдера.

### 🛠 Исправления стабильности и защиты от сбоев
* **Автовосстановление при смене IP провайдера / PPPoE CGNAT:**
  * Хук `/etc/hotplug.d/iface/95-awgswitch` при событии `ifup`/`ifupdate` на интерфейсе `wan` автоматически перезапускает `awg0` и обновляет `https-dns-proxy`, устраняя «залипание» сокетов после переподключения PPPoE.
* **Приоритет AmneziaWG 3.1 (`2Grey/awg-openwrt`):**
  * Автоустановщик и ссылки на ручное скачивание теперь используют репозиторий `2Grey` с полной поддержкой AmneziaWG 3.1 (`S3/S4`, `I1..I5`, `HeaderProtectionKey`).
* **Блокировка IPv6 DNS утечек и `force_ip_family='4'`:**
  * Запрет утечек DNS по IPv6 через `awg_vpn_input` (`icmpv6 port-unreachable` / `tcp reset`) и отключение IPv6 RA/DHCPv6 при отсутствии IPv6 на WAN.
* **Чистое удаление через стандартный `opkg remove`:**
  * Скрипт `prerm` при полном удалении пакета (не при обновлении) автоматически очищает правила `awg0`, `awgrule_*`, `zone_awg` и `zapret`-метки.

## Версия 2.2.0 (Релиз)

### 🚀 Новые возможности
* **Изоляция DNS для VPN-устройств через `nftables`:**
  * Устройства, переключенные в туннель AmneziaWG (`awg0`), автоматически получают чистый европейский DNS Cloudflare (`1.1.1.1:53` Anycast) через туннель.
  * Исключены конфликты SmartDNS (подмена IP от GeoHide EU `109.61.17.142 ≠ 31.25.239.132`), вызывавшие блокировки «Подозрительный трафик» от Google Gemini и Claude.
* **Полная совместимость с GeoHide EU + Zapret:**
  * При отключении устройства от VPN перехват DNS немедленно снимается.
  * Устройство мгновенно возвращается к прямому выходу в интернет с активным `zapret` и роутерным DoH (`https-dns-proxy` GeoHide EU -> Cisco OpenDNS Frankfurt).
* **Пользовательские псевдонимы и переименование устройств:**
  * Добавлена кнопка переименования `✏️` для любого устройства прямо в веб-интерфейсе LuCI.
  * Имена сохраняются в `/etc/awgswitch/aliases.json` и не сбрасываются при смене IP по DHCP.
* **Автоопределение производителей и типов устройств:**
  * Определение вендоров по OUI MAC-адресов (ASUS, Micro-Star MSI, Яндекс Станция, FN-Link TV Box, Raspberry Pi, Xiaomi, Samsung, Apple, устройства с приватными/рандомизированными MAC).
* **Защита ПК с сессией ассистента Antigravity:**
  * Бейдж `[Этот ПК (Сессия Ассистента)]` в списке устройств.
  * Предупреждающее модальное окно при попытке отключить этот ПК от VPN или при нажатии «Выключить для всех».
* **Интеллектуальная диагностика соединения:**
  * Тесты доступности Anthropic, OpenAI, YouTube и произвольных доменов с параллельным сравнением трафика через VPN (awg0) и напрямую (WAN).
  * Резолв доменов через европейский шлюз туннеля для точного определения IP и локации (`ip=109.61.17.142`, `loc=FI`, `colo=HEL`).

### 🛠 Исправления и оптимизации
* **Детерминированные правила UCI:** Все правила policy routing переведены на именованные секции `network.awgrule_<IP>`, что полностью устранило ошибки сдвига анонимных индексов `@rule[X]`.
* **Hotplug-синхронизация:** Добавлены хуки `/etc/hotplug.d/iface/95-awgswitch` и `/etc/hotplug.d/firewall/95-awgswitch` для автоматической синхронизации IP-сетов при любых перезагрузках сети или `fw4`.
* **Безопасная установка/обновление:**
  * Скрипт `prerm` больше не отключает интерфейс `awg0` при переустановке пакета.
  * Скрипт `postinst` автоматически проверяет наличие `awg0` и восстанавливает маршрут по умолчанию в таблицу 100.
